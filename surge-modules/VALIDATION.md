## 已验证的兼容修复

- Surge 请求超时按秒设置；JavaScriptCore 中仅在 `clearTimeout` 可用时调用。
- 通知失败也必须到达 `$done()`；测试覆盖通知故障和缺少 `clearTimeout`。
- Seek 捕获支持实际 Service Worker 的本站来源，保留个人资料及账号 ID 校验。按官网最小请求格式省略正文、Content-Type 和 Origin，并先读取今日记录以避免重复提交。实测无需 Refract 签名；候选签名及密钥更新代码已移除。
- 科研通识别“今天已于某时间签到”的真实响应，不能仅根据 `code=1` 判断重复。
- 漫画使用 API 要求的 `platform=ios`，试运行不调用 Exchange，结果不确定时不自动重发交易。
